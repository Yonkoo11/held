The consensus log

Every state change writes a line to a Hedera Consensus Service topic as it happens, grouped below by the job it belongs to. The service writes them; the network orders and timestamps them, so the sequence is not ours to edit afterwards.

The topic holds more jobs than the register does, and that difference is worth explaining rather than hiding. The topic is append-only and spans every run of this service, including development machines, whereas this deployment's own storage started empty. If the register were lost tomorrow, everything in it would still be on the topic, and we have no way to go back and change that.
